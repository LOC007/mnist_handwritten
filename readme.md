关于LOC的项目：
在不借助torchvision的前提下，手搓IDX二进制解析，做出一个训练模型：两卷积加两池化和两全连接结构。结构如下：
输入 x  (1, 1, 28, 28)

conv1 · Conv2d(1→32, 3×3, p=1)  (1, 32, 28, 28)

pool1 · MaxPool2d(2)  (1, 32, 14, 14)

conv2 · Conv2d(32→64, 3×3, p=1)  (1, 64, 14, 14)

pool2 · MaxPool2d(2)  (1, 64, 7, 7)

flatten(1)  (1, 3136)

fc1 · Linear(3136→128)  (1, 128)

fc2 · Linear(128→10)  (1, 10)
训练方式：
1.解析 4 个 IDX 文件 → 6 万训练 + 1 万测试，归一化到 0~1、标签转 long
2.TensorDataset + DataLoader(batch_size=64, shuffle=True)
3.CrossEntropyLoss + Adam(lr=1e-3)，5 个 epoch
4.每批五步：前向 → 算 loss → 去梯度· → 反向 → step
5.评估：model.eval() + no_grad，1 万张图上 9907 张正确，99.07%
做到在1万张没见过的图上考99分。
在做验证数据真伪时输的是7但标签输出是5，但用交叉验证标签是5没错
